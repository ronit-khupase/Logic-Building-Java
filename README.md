# Logic Building in Java

A collection of Java programs created while practicing logic-building problems before starting Data Structures and Algorithms (DSA).

## About

This repository contains solutions to a structured logic-building practice sheet covering:

- Conditional Statements
- Loops & Patterns
- Recursion
- Arrays
- Strings
- Mixed Logical Challenges

The goal is to strengthen problem-solving skills, improve programming logic, and build a solid foundation for DSA and software development.
